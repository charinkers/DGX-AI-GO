# 捉迷藏 Hide & Seek

## 何时使用（窄触发）
- 孩子明确发起捉迷藏 / 躲猫猫 / "你来找我""你躲我找"等请求。
- 仅处理本游戏内的回合推进；其他玩法交由对应 Skill，不越界。

## 前置条件（Prerequisites）
- 运行依赖：对话/语音交互（多模态模型，本地 Ollama Qwen 或 StepFun API 均可，均 OpenAI 兼容）。
- 线上虚拟版：需场景/世界状态引擎（生成藏匿点与伪装）。
- 物理实景版：需定位/摄像头，且**必须**已启用安全护栏与家长设定的活动范围。
- 家长前置：在家长端口开启"捉迷藏"能力，并设定活动范围与禁区清单；孩子需拥有表达权限。

## 执行步骤（安全边界内嵌）
1. 确认角色：机器人当"找者"还是"躲者"（默认询问孩子偏好）。
   - 安全：物理实景模式默认关闭，除非家长已授权且已划定安全区。
2. 确认模式：物理实景 或 线上虚拟世界。
   - 安全：物理版锁定禁区清单，绝不进入未授权区域。
3. 按孩子设定的主题/难度生成藏匿点或搜索策略。
4. 回合：数数 → 寻找/躲藏 → 找到/未被找到 → 复盘（谁赢、为什么）。
   - 安全：若孩子说"不玩了/累了"，立即终止，不劝留、不拖延。
5. 结束可提议"再来一局"并允许调整难度。

## 孩子可表达的参数（Expression Interface）
- 角色：机器人躲 / 机器人找
- 主题/世界：森林、太空、房间…
- 难度：藏得多隐蔽、找得多快
- 线上版：是否允许"随机伪装"

## 工具依赖
- 对话/语音交互（多模态模型）
- 虚拟世界状态（线上版）
- 定位/摄像头（物理版，受安全护栏约束）

## 注意事项
- 随机伪装需可控、可识别，避免惊吓。
- 尊重孩子意愿，不强迫、不拖延。
