# 青少年/儿童智能机器人 · 国内国际调研 调研报告
> 生成日期：2026-09-22 · 团队：Rosy / flower / 晶晶 / 王小猴

## 一、学术调研（国内外）
- **Socially Assistive Robots (SAR) for children**（国际）：社交辅助机器人在儿童陪伴/干预场景中，长期效果取决于关系建立而非功能数量。来源：USC SAR Lab 等公开研究
- **Child-Robot Interaction (HRI) 综述**（国际）：儿童对机器人的信任与「对手感/平等感」强相关，纯语音助手形态留存显著更低。来源：HRI 会议公开综述
- **国内教育机器人标准与测评**（国内）：国内市场以编程教育/早教故事机为主，强互动陪玩品类尚属空白。来源：公开行业报告

## 二、市场调研
### 国内

- **阿尔法蛋（科大讯飞）**｜¥300-1000｜3-8 岁｜强项：语音问答/学习内容生态｜短板：偏早教故事机，无真实游戏对手感
- **乐高 SPIKE / Boost**｜¥1000-2500｜6-10 岁｜强项：建构+编程教育｜短板：无持续陪伴关系，拼完即止
- **大疆 RoboMaster EP**｜¥2500+｜8+ 岁｜强项：竞技对抗专业度｜短板：偏竞赛器材，非日常陪伴
### 国际

- **Moxie (Embodied)**｜$500-800｜5-10 岁｜强项：社交陪伴+情感关系｜短板：订阅制后停服风险，无国内本地化
- **Miko 3**｜$250-300｜5-10 岁｜强项：AI 对话+内容应用｜短板：游戏性与身体互动弱
- **Vector / Cozmo (DDL)**｜$250-400｜8+ 岁｜强项：桌面宠物感/性格｜短板：无教育闭环，生态停滞

### 市场洞察
- 国内=教育器材/故事机，国际=桌面陪伴；**强互动陪玩+孩子共创**品类空白，正是本项目卡位。

## 四、需求分析（Kano 分层）
| 层级 | 需求 |
|---|---|
| 基本型 | 内容安全过滤、隐私数据不出本地（parent） |
| 基本型 | 家长能开放/关闭定制能力（权限分层）（parent） |
| 基本型 | 像机械狗一样可以摸、可以摇（child） |
| 基本型 | 身上有画板，我可以在它身上画画（child） |
| 期望型 | 能陪我玩捉迷藏，会藏会伪装（child） |
| 期望型 | 语言对战不赖皮，也不能轻易让我赢（child） |
| 期望型 | 玩中有学习价值（音乐/语言/编程思维）（parent） |
| 期望型 | 功能多：放音乐、用脸看视频、帮我做事（child） |
| 魅力型 | 徒步帮我采声音，组成今日心情旋律（child） |
| 魅力型 | 站我这边，不是妈妈派来的眼线（child） |
| 魅力型 | 机器人是独一无二的（孩子自己定制 IP）（parent） |

## 五、需求提炼 Top5

1. **内容安全过滤、隐私数据不出本地**（得分 12，基本型，来源 parent）
2. **能陪我玩捉迷藏，会藏会伪装**（得分 11，期望型，来源 child）
3. **家长能开放/关闭定制能力（权限分层）**（得分 11，基本型，来源 parent）
4. **语言对战不赖皮，也不能轻易让我赢**（得分 10，期望型，来源 child）
5. **玩中有学习价值（音乐/语言/编程思维）**（得分 10，期望型，来源 parent）
