# 青少年机器人调研 Research Pipeline

## 何时使用（窄触发）
- 团队需要针对"青少年/儿童机器人"做学术/市场/问卷/需求类调研时。
- 本 Skill 服务团队研究，不面向儿童终端交互；儿童陪玩场景交由 hide-and-seek / world-battle / sound-melody。

## 前置条件（Prerequisites）
- 运行依赖：纯 Python 标准库即可跑通离线全流程（`scripts/main.py`）。
- 输入数据（三选一）：内置演示数据 / 自备 `data.json`（academic + market + survey 三段结构，见报告示例）/ 由 Agent 现场检索后喂入。
- 图片/视频产出依赖：DGX Spark 上 ComfyUI(FLUX+PuLID) 生成图片、StepFun 生成旁白；或平台多模态生成工具。
- 团队前置：确认调研范围（国内/国际）、样本来源、隐私口径。

## 执行步骤（安全边界内嵌）
1. **学术调研**：收集国内外学术研究、行业标准，逐条记录出处。
   - 安全：仅收录可溯源来源，禁止无出处结论入报告。
2. **市场调研**：国内外竞品的价位、年龄带、强项、短板逐项建档。
   - 安全：数据标注"截至日期"，避免过期价格误导决策。
3. **问卷收敛**：问卷/访谈数据清洗，按需求聚合票数与提及次数。
   - 安全：儿童数据匿名化（仅 P01/C01 编号），原声仅作需求证据，不外传。
4. **需求分析**：Kano 分层（基本型/期望型/魅力型）+ 加权得分（票数+2×提及）。
   - 安全：安全类需求自动归入"基本型"，不可被娱乐需求淹没。
5. **需求提炼**：输出 Top-N 需求及用户原声对照。
6. **成果生成**：产出 `调研报告.md` + `需求优先级.svg` + `调研动态简报.svg`（自动轮播，离线视频感）；图片/视频 Prompt 写入报告，由多模态端执行。

## 团队可配置参数
- 调研范围（国内 / 国际 / 双线）
- 问卷样本与角色（child / parent）
- Kano 归类表（THEME_KANO，可按项目调整）
- 输出风格（图表配色、简报页数、视频时长）

## 工具依赖
- 本地执行：Python 3 标准库（零依赖）
- 检索类调研：由 Agent（王小猴）联网检索后喂入 `--data data.json`
- 图片：ComfyUI（DGX Spark）/ ImageGen 类工具
- 视频：VideoGen / StepFun 音视频能力（离线降级 = SVG 动态简报）

## 可执行入口（Agent 调用）
- `scripts/main.py`：离线跑通 收敛→分析→提炼→产出 全链路。
- 自备数据：`python scripts/main.py --data mydata.json --outdir outputs`
