# 作业伙伴 · 休息教练 Homework Coach

## 何时使用（窄触发）
- 孩子说"开始写作业""我写完一项了""陪我休息一下"。
- 或 `evening-flow` 进入作业时段后由 harness 调度本 Skill 接管作业块。
- 仅处理作业块的逐项推进与休息引导；整晚时段播报交由 `evening-flow`。

## 前置条件（Prerequisites）
- 运行依赖：`scripts/main.py`（纯 Python 标准库，无需 key）维护作业会话状态；运动引导可配合机身动作（移动/转圈/音乐）。
- 家长前置：设定今晚作业项数（默认校内4项+课外2项，可语音修改）；设定休息活动的安全范围（室内活动区域清空障碍物）。

## 执行步骤（安全边界内嵌）
1. 开始会话：和孩子确认"今晚几项作业"（默认校内3-4项+课外1-2项），生成任务清单。
   - 安全：项数由孩子/家长确认，AI 不擅自加量。
2. 逐项专注：孩子写作业，机器人保持安静陪伴（低亮度表情屏）。
3. 孩子报告"写完一项" → 播报鼓励 + 主动发起5分钟休息：建议身体活动（拉伸/跳绳/机器人领操）。
   - 安全：休息活动限室内安全动作，运动前提醒周围清空障碍物；不引导跑跳以外的剧烈活动。
4. 休息结束 → 回到下一项，直到清单清空。
5. 全部完成 → 小结今晚成果（项数+获得积分），交还自由时间。
   - 安全：未完成不批评；若孩子中途放弃，只说接纳话术并记录进度供明天继续。

## 孩子可表达的参数
- 今晚作业项数与顺序（先校内还是先课外）
- 休息活动类型（跟机器人做操 / 自己跳绳 / 安静喝水望远）
- 是否需要计时（专注无倒计时 / 轻提醒）

## 工具依赖
- 本地会话状态（state.json，与 evening-flow 共享打卡数据）
- 机身动作与音效（领操、庆祝）
- 可选：对接成长星球 App 自动完成 homework/breaksport 打卡

## 可执行入口（Agent 调用）
- `scripts/main.py start --school 4 --extra 2`：开始今晚作业会话。
- `scripts/main.py done-item`：完成一项 → 返回鼓励话术 + 5分钟休息引导（含机器人领操建议）。
- `scripts/main.py rest-done`：休息结束，进入下一项。
- `scripts/main.py finish`：小结今晚成果。

## 注意事项
- 核心价值 = 把"休息5分钟"变成孩子期待的环节（机器人领操），而不是任务间的空档。
