# 放学流程时间线管家 Evening Flow

## 何时使用（窄触发）
- 孩子说"现在该干嘛""今天放学流程是什么""接下来做什么"。
- 或 harness 在预设时段（16:10/16:30/19:20/20:30/20:50）主动唤醒本 Skill 播报。
- 仅处理流程时间线的"播报与推进"；作业块内的逐项计时与休息教练交由 `homework-coach`。

## 前置条件（Prerequisites）
- 运行依赖：`scripts/main.py`（纯 Python 标准库，无需 key）读取本地 `state.json`；可选对接成长星球 App 的流程接口同步打卡数据。
- 数据前置：家长在配置中设定当晚流程（默认：16:10 到家缓冲 → 16:30 作业时间 → 19:20 体能 → 20:30 英语听读 → 20:50 阅读），可按平日/周末切换模板。
- 家长前置：开启"流程提醒"能力；设定机器人主动开口的时段白名单（避免上课时间打扰）。

## 执行步骤（安全边界内嵌）
1. 读取今日流程与完成状态，定位"当前时段"（第一个未完成的动作时段）。
2. 播报当前时段：时间 + 动作 + 一句鼓励（TTS 友好短句）。
   - 安全：只播报家长配置内的时段；夜间 21:30 后自动静音，不催促。
3. 孩子语音确认完成（"我做完啦"）→ 记录到 state，推进下一时段。
4. 孩子表示没做完/不想做 → 不扣分不重复催促，改说接纳话术并留补做窗口。
   - 安全：单时段播报不超过 2 次；绝不施加负面评价或倒计时压力。
5. 全部时段完成 → 播报庆祝语，剩余时间交还孩子自主安排。

## 孩子可表达的参数
- 今天想先做哪一项（可调换时段顺序）
- 是否启用到点主动播报（还是只在被问时回答）
- 庆祝方式（安静鼓掌 / 机器人起飞转圈）

## 工具依赖
- 本地状态读写（state.json，数据不出本机）
- TTS 播报与表情屏（机身能力）
- 可选：与成长星球 App 打卡数据双向同步

## 可执行入口（Agent 调用）
- `scripts/main.py now`：返回当前该做的时段 + 播报话术（JSON，含 say 字段）。
- `scripts/main.py done homework`：记录完成；作业块动作会同时返回"休息5分钟"引导。
- `scripts/main.py status`：今晚流程进度总览。

## 注意事项
- 机器人是"到点的陪伴"不是"监工"：错过不追责，语气永远接纳。
