# 今日总结 · 星账本 Evening Review

## 何时使用（窄触发）
- 孩子说"今天总结一下""我有多少分""我想兑换XX""今天赚了多少"。
- 或 harness 在 21:00 总结时段主动唤醒。
- 仅处理回顾、账本播报与兑换登记；流程推进与作业计时交由对应 Skill。

## 前置条件（Prerequisites）
- 运行依赖：读取 `evening-flow/scripts/state.json` 的打卡与积分数据；兑换清单来自家长配置（与成长星球 App 的奖品商城一致）。
- 家长前置：开启"兑换登记"能力；设定哪些兑换需家长确认后生效（大额兑换默认需确认）。

## 执行步骤（安全边界内嵌）
1. 回顾今天：按流程时间线逐项确认（已完成打勾，未完成的用接纳话术带过，不点名批评）。
2. 问一个开放问题："今天最有意思的一件事是什么？"——记录为孩子的一句原话（存入成长档案）。
   - 安全：孩子可选择跳过不回答；记录内容仅存本地，数据不出本机。
3. 播报积分账本：累计获得 / 已兑换 / 剩余可用（三格口径，与 App 兑换专区一致）。
4. 兑换意愿：孩子说出心愿 → 对照奖品清单告知所需积分与差距；积分足够则登记兑换意向。
   - 安全：兑换仅登记意向，实际兑换需家长在 App 确认；不引导攀比消费。
5. 明日预告：播报明天流程的关键时段（如"明天16:30作业时间见"），互道晚安。

## 孩子可表达的参数
- 今天的心情标签（结合心情气象台）
- 想重点回顾哪个时段
- 心愿兑换目标（可自定义心愿，交家长协商）

## 工具依赖
- 本地状态读取（state.json，数据不出本机）
- TTS 播报；可选：成长档案追加语音原话

## 可执行入口（Agent 调用）
- 状态读取复用 `evening-flow/scripts/main.py status`；兑换清单与登记接入成长星球 App 兑换专区接口（进行中）。
- 说明文档版先行：脚本化入口在赛程第二周补齐（不阻塞 SKILL 设计评审）。

## 注意事项
- 总结是"看见成长"不是"批改作业"：先讲做到的，没做到的一笔带过。
