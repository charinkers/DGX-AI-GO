# 儿童作品社区 · kidcomm-community

让孩子把作品**发布到社区**、**浏览同龄人的作品**、**互相点赞**，并支持**私有保存**（仅自己可见、不进公开画廊）。社区本身即「激发创造、鼓励创造」的课堂。

## 何时使用
- "我想把我的机器人发到社区" / "发布我的作品" → 发布（默认公开/可分享）
- "看看大家的机器人" / "社区里有什么" → 列出公开作品
- "给 XX 点个赞" / "这个好酷" → 点赞
- "这个我只想自己留着" / "设为私有" → 切换为私有（仅自己保存）

## 行为准则
- **表达权在孩子**：是否分享由孩子/家长决定；默认尊重"不想分享"的选择。
- **私有 != 删除**：私有作品仍保存在本地，作者随时可再发布。
- **安全**：社区内容入口仍过安全护栏（平台强制前置）；不对孩子暴露他人隐私。

## 入口
`scripts/main.py --query "<自然语言>"` 会将请求转发到 `community/store.py`：
- 发布 → `store.publish(contract, title, author, public)`
- 浏览 → `store.list_public()`
- 点赞 → `store.like(work_id)`
- 切换 → `store.set_privacy(work_id, public)`
