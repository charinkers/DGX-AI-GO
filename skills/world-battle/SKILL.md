# 语言游戏 · 世界对战 World Battle

## 何时使用（窄触发）
- 孩子提出"我们编个世界来打""互相出招 PK""看谁赢"等。
- 仅处理本对战内的世界构建、出招与判定；其他玩法交由对应 Skill。

## 前置条件（Prerequisites）
- 运行依赖：叙事/语言生成（多模态模型，OpenAI 兼容）；规则状态机为本地逻辑，无需外部 API。
- 家长前置：开启"对战"能力；设定是否允许中途规则迭代、难度上限档位。

## 执行步骤（安全边界内嵌）
1. 与 child 共建世界设定（背景、角色、力量体系）——child 是 co-author。
2. 明确先手与回合结构；**必须向孩子完整宣读当前生效规则**（透明，禁止默认隐藏规则）。
   - 安全：规则一旦声明即锁定，不得偷偷改数值或加隐藏优势。
3. 回合制出招：双方轮流，AI 按规则判定胜负/效果。
   - 安全：判定严格按已声明规则，禁止临时改数值、加隐藏优势。
4. 允许中途规则迭代（如"这招太强加冷却"），但**需双方同意并记录**后方可生效。
   - 安全：单方不得私自改规则。
5. 复盘：解释本回合判定依据，让孩子理解为什么赢/输。
   - 安全：语言保护自尊，输赢都是游戏，避免贬低式语言。

## 设计约束（来自孩子原话，必须编码进技能）
- **别太赖皮**：规则透明一致，判定可解释。
- **不能轻易让她赢**：难度动态但"可感知"，非暗中放水。
- 实现：透明规则引擎 + 可解释难度旋钮（非黑箱 rubber-banding）。

## 孩子可表达的参数
- 世界主题、角色设定
- 先手、回合长度
- 难度档（挑战度）
- 规则迭代权限（哪些规则可中途改）

## 工具依赖
- 叙事/语言生成
- 规则状态机（维护世界状态与判定）
- 难度调节器（透明、可解释）
