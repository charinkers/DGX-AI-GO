# 声音采集 · 心情旋律 Sound → Melody

## 何时使用（窄触发）
- 孩子说"我们出去录声音吧""把今天的声音做成歌""学琴用的小曲子"。
- 仅处理声音→旋律的创作流程；其他玩法交由对应 Skill。

## 前置条件（Prerequisites）
- 运行依赖：音频采集（麦克风或音频文件）；声音理解（DGX Spark 本地推理或 API）；离线合成用 `scripts/compose.py`（纯标准库，无需 key 生成 WAV + ABC 简谱）。
- 家长前置：开启"声音采集"能力；设定是否允许户外采集、隐私边界（不录陌生人对话）。

## 执行步骤（安全边界内嵌）
1. 徒步/散步中实时或分段采集环境声音（鸟鸣、风、脚步、水声、人声…）。
   - 安全：户外采集须避开他人对话/敏感声源，并提示注意安全。
2. 分类与标注：识别声源类型、情绪色彩。
3. 由孩子打"今日心情"标签（开心/安静/兴奋…）。
   - 安全：心情标签由孩子主导，AI 不替代创作判断。
4. 将选定声音映射为音符/节奏，合成一段短旋律。
5. 可选：输出简谱/钢琴谱，供孩子用钢琴弹奏（呼应学琴）。

## 孩子可表达的参数
- 今日心情标签
- 想纳入哪些声音（自然/城市/人声）
- 旋律风格（舒缓/欢快）
- 是否生成钢琴可弹奏版本

## 工具依赖
- 音频采集与理解（DGX Spark 本地推理，隐私友好）
- 声音 → 音符映射与音乐生成（离线版见 `scripts/compose.py`，纯标准库实现，无需 key 即可生成 WAV + ABC 简谱）
- 可选：简谱 / MIDI 输出

## 可执行入口（Agent 调用）
- `scripts/main.py`：Agent 命中本技能时自动调用，离线即可生成「今日心情旋律」WAV 与 ABC 简谱。
- 真实采集：`python scripts/main.py --sounds sounds.json`（sounds.json = `[{name, mood, intensity}]`）。

## 注意事项
- 保持"孩子主导创作"，AI 是编曲助手不是替代。
